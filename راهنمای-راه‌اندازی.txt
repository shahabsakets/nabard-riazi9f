نبرد ریاضی نهم — نسخه Firebase (بدون نسخه آینه)

محتویات:
- index.html: بازی اصلی با اتاق آنلاین دونفره روی Firebase Realtime Database
- question-bank-1150.json: بانک سؤال
- firebase-database.rules.json: قوانین امنیتی پیشنهادی دیتابیس

راه‌اندازی کوتاه در پروژه nabard-riazi9:
1) Firebase Console → Authentication → Sign-in method → Anonymous را فعال و Save کن.
2) Realtime Database → Rules را باز کن؛ محتوای firebase-database.rules.json را کامل جایگزین کن و Publish بزن. این قوانین اجازه می‌دهند اتاق‌های در انتظار فقط با دانستن کد قابل مشاهده باشند؛ پس از شروع بازی فقط دو عضو اتاق می‌توانند اطلاعات را بخوانند و هر بازیکن فقط پاسخ خودش را ثبت کند.
3) برای انتشار فایل index.html و question-bank-1150.json را روی Firebase Hosting قرار بده. فایل PHP و MySQL لازم نیست و در این بسته حذف شده‌اند.
4) آدرس سایت را در دو گوشی با اینترنت‌های جدا باز کن؛ یکی «ساخت اتاق» و دیگری «ورود با کد» را انتخاب کند.

توجه مهم:
- این نسخه از Firebase Anonymous Authentication استفاده می‌کند. قبل از استفاده عمومی، حتماً قوانین بالا را Publish کن؛ به Test Mode عمومی اکتفا نکن.
- نسخه حاضر تبدیل اولیهٔ مسیر اتاق و پاسخ‌های آنلاین است و باید پیش از انتشار عمومی با دو گوشی واقعی آزمایش شود.
- محاسبه امتیاز و صحت پاسخ هنوز در مرورگر انجام می‌شود؛ برای رقابت رسمی/جایزه‌دار، باید منطق امتیازدهی به محیط سرور امن منتقل شود.
- فایل firebase-database.rules.json را در صفحه Rules به‌عنوان JSON وارد کن، نه در بخش Data.
