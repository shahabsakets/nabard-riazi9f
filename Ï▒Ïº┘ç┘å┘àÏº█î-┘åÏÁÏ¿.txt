نسخه جدید نبرد ریاضی نهم — اتاق خصوصی + جست‌وجوی تصادفی Firebase

۱) Firebase Console → Realtime Database → Rules
کل محتوای firebase-database.rules.json همین بسته را جایگزین قوانین قبلی کنید و Publish بزنید.
توجه: بدون این مرحله جست‌وجوی تصادفی با خطای Permission denied روبه‌رو می‌شود.
۲) Firebase Console → Authentication → Sign-in method → Anonymous باید Enabled باشد.
۳) در GitHub مخزن مربوط به سایت nabard-riazi9f، فایل‌های index.html و question-bank-1150.json را در ریشه مخزن جایگزین کنید (Commit changes). خود ZIP را آپلود نکنید.
۴) پس از انتشار GitHub Pages، آدرس https://shahabsakets.github.io/nabard-riazi9f/ را با تازه‌سازی باز کنید.
۵) تست خصوصی: گوشی اول رقابت آنلاین → ساخت اتاق → کد هشت‌حرفی؛ گوشی دوم رقابت آنلاین → ورود با کد.
۶) تست تصادفی: هر دو گوشی رقابت آنلاین → بازی آنلاین تصادفی → شروع جست‌وجو؛ صفحه‌ها را باز نگه دارید.

توجه: این نسخه از نظر نحو JavaScript و JSON بررسی شده اما اتصال زنده دو گوشی به پروژه Firebase شما از این محیط قابل آزمایش نبوده است. امتیازدهی فعلی در مرورگر انجام می‌شود و برای مسابقه دارای جایزه یا حساس به تقلب، نیاز به امتیازدهی سمت سرور دارد. قوانین موجود را پیش از عرضه عمومی با توجه به نیازهای نهایی امنیتی بازبینی کنید.
